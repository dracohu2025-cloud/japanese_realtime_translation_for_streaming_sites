部署日期：2026-09-07。入口：<https://kotoba-beta.dracohu2025.workers.dev/pricing>。

## 已上线

- Workers `kotoba-beta` 提供 HTTPS 页面、邮箱登录和支付接口；WSS 地址为 `wss://kotoba-beta.dracohu2025.workers.dev/stream`。
- `KotobaBeta` Durable Object 使用自己的持久化 SQLite 保存账号、会话、邮件限频和每个账户的账本，不依赖本机进程或本机数据库。

## 使用

1. 在 Chrome 扩展管理页面刷新已加载的 `extension/`，确认版本为 0.1.6。若之前从解压目录安装，应更新该目录，或重新加载本项目的 `extension/` 文件夹。
2. 打开上述线上入口，用受邀邮箱和邮件验证码登录；线上账号和额度与 8791/8792 本机测试数据独立。
3. 领取试用，点击“获取插件连接码”。在扩展设置填写页面显示的服务地址和连接码，保存后回到视频页启动翻译。
4. 连接码最长一小时有效，且不超过所属网页会话有效期；退出登录后失效。连接码的哈希、所属账户、会话及到期时间保存在 SQLite，部署或对象重建后仍可校验有效凭据。旧版本仅存内存，升级后需重新获取一次；部署仍可能中断正在进行的音频连接，需要重新开始翻译。

插件 0.1.14 起在 `chrome.storage.session` 保留同一连接码和服务地址的账户展示快照（凭据哈希、余额、查询时间，最长一小时）。重新打开弹窗先恢复主界面，将旧值标为“上次查询余额”，同时重新查询云端。网络错误不作为退出登录，明确的 `LOGIN_REQUIRED` 会清除快照。新凭据、浏览器重启或扩展重新加载后需要首次验证。快照仅用于展示，启动翻译和扣时始终由服务端鉴权与账本决定。

## 部署与密钥

```sh
npm run cloud:assets
npm run cloud:test
npm run cloud:deploy
```

配置在 `wrangler.jsonc`。域名先使用账户的 workers.dev 地址，未改动现有网站及 Zoho 邮件 DNS。账户首次启用了 `dracohu2025.workers.dev` 子域。

Cloudflare Secrets 保存 `BETTER_AUTH_SECRET`、`SONIOX_API_KEY`、`RESEND_API_KEY`、`STRIPE_SECRET_KEY`、`STRIPE_WEBHOOK_SECRET`。本机 `.env.cloud-secrets.json` 为忽略提交的凭据备份，不得复制到静态资源或扩展包。

更换凭据时使用 `wrangler secret bulk` 安全输入；不要把值写入命令参数、日志或配置中的 vars。保持认证密钥稳定，否则已有登录会话失效。当前 Stripe 内测复用 CLI 的测试凭据，正式收款前应配置专用服务端正式密钥及独立正式回调；现有代码主动拒绝 live 模式，不能只替换密钥即收款。

`.dev.vars` 是本机 workerd 的假凭据夹具，不用于部署，也不会发送真实邮件。`output/` 和 `.wrangler/` 不提交。

## 当前边界

这是封闭内测部署，不是正式收费上线。一个 Durable Object 协调所有内测账户，每个账户一路音频，整体最多三路，单次最多 60 分钟。没有进行负载或长期稳定性验证。上游 WebSocket 存活时对象不休眠，运行成本不能按纯静态网页估算。

认证请求串行，账本按账户串行；每个账本保存为独立 SQLite 行。SQL 适配器不伪装支持异步事务，验证码限频使用同步事务。正式扩容前应拆分每账户协调对象、缩小支付网络请求占用的账本队列，并补充恢复对账。

扣时语义仍为“上游发送队列接受的音频”，跨系统发送和持久化不是原子事务；供应商异步失败或异常断线后的补时、退款/争议权益处理、监控告警、开放注册防刷、公开隐私与服务条款仍待正式上线前完成。线上不持久保存音频和字幕正文。

参考：[Durable Object SQLite](https://developers.cloudflare.com/durable-objects/api/sqlite-storage-api/)、[Workers WebSocket](https://developers.cloudflare.com/workers/runtime-apis/websockets/)、[Better Auth 数据库适配](https://better-auth.com/docs/adapters/other-relational-databases)。
