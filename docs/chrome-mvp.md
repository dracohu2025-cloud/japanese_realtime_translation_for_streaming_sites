# Kotoba Live：Chrome 本机首版

定位：专注日语的通用实时翻译工具。当前 Chrome 版支持日语语音到中文、英语、韩语等 11 种目标语言，保留原声并可显示日语原文。

这是可加载运行的开发版本。尚未发布 Chrome Web Store、接入订阅或部署公网服务。网页中的演示使用固定文本，真实字幕由扩展采集音频后生成。

## 安装与启动

需要桌面 Chrome 116 或更高版本，以及 Node.js 22 或更高版本。

1. 在项目目录执行 `npm ci`。仅运行本机中继时可执行 `npm ci --omit=dev`。
2. 将 `.env.example` 复制为 `.env`，在本地编辑器填写 `SONIOX_API_KEY`。不要把供应商密钥填入扩展或聊天记录。
3. 执行 `npm start`，打开 <http://127.0.0.1:8787>。未配置密钥时仍可预览界面，但不能进行真实翻译。
4. 打开 Chrome 的 `chrome://extensions`，开启开发者模式，选择“加载已解压的扩展程序”，加载项目的 `extension` 目录。
5. 在本机控制台点击“复制配对码”，进入扩展设置并粘贴保存。服务地址默认 `ws://127.0.0.1:8787/stream`。
6. 打开并播放普通网页中的日语音视频，点击工具栏的 Kotoba Live 扩展，再点击“开始翻译”。完成后点击“停止”。

本机服务默认每次启动生成新的配对码；重启后需重新配对。如希望固定配对码，可在 `.env` 的 `RELAY_TOKEN` 中设置至少 24 个字符的随机值。供应商 API key 始终由本机 Node 进程持有。

`npm run package` 生成 `dist/kotoba-live-0.1.5.zip`。本地安装需先解压，再加载解压后的扩展目录；ZIP 本身不是可双击安装的程序，也不包含本机中继或供应商密钥。

## 已实现

- 用户主动开启当前标签页音频采集；不申请所有网站的永久访问权限。
- 16 kHz 单声道 PCM 音频以 100 ms 分块发送；原声播放使用设备原生采样率。
- Soniox `stt-rt-v5` 流式识别及日语到所选目标语言的单向翻译；运行中更改目标会重新连接。
- 日语原文、中文字幕、临时结果修订；字体和原文显示可调。
- 字幕默认居中显示在视频画面内下方，跟随播放器尺寸及页面滚动；进入容器全屏时移入全屏容器。视频滚出视口时隐藏字幕，纯音频页面保留窗口底部布局。
- 最多 30 个术语、每个最多 60 字符，以及最多 1,000 字符的背景说明。
- 顶层音视频暂停/跳转时断开上游，恢复播放时重新连接并清除旧字幕；停止时关闭采集音轨。
- 本机配对验证、来源校验、连接数限制、音频速率检查、超时和最长会话时限。
- 本机配置页、字幕样式演示和扩展 ZIP 打包。

供应商接入封装于 `server/soniox.js`，通过 `createApp` 的工厂参数注入；字幕缓冲不依赖供应商 SDK。本轮按 KISS/YAGNI 使用原生 JavaScript、Node 内置 HTTP 和一个 WebSocket 运行时依赖，没有为未上线的订阅引入数据库或账户系统。

## 字幕与费用操作（Chrome 0.1.3）

- 开启翻译后，拖动字幕上方的「⠿ 拖动字幕」调整位置；「复位」恢复默认位置。操作柄也支持方向键。默认位置跟随播放器；手动拖动可移至整个网页可视区域，拖动后不随播放器滚动，窗口缩放时保持在视口内。当前页面保留位置，刷新后重置；浏览器地址栏、工具栏等 Chrome 界面不属于网页区域。
- 弹窗直接选择目标语言；运行中切换会短暂重连。中文、英语、韩语、西班牙语、法语、德语、葡萄牙语、俄语、越南语、泰语、印尼语可选。
- 弹窗中目标语言下方的「显示日文原文」开关立即生效；字幕旁还提供「隐藏日文原文 / 显示日文原文」按钮，设置会保存并与弹窗同步，不重连、不改变语音服务的转写输出，因此不降低转写费用。
- 弹窗显示本次费用预估、Soniox 已归账金额、已归账段数和查询时间。展开「预估与真实费用怎么算？」可查看完整规则，另见 [费用规则](billing.md)。
- 开发版更新后，在 Chrome 扩展管理页重新加载 Kotoba Live，再刷新视频页并开始翻译。

本轮验证：新增费用估算、暂停冻结、语言重连、Usage Logs 翻页去重及异常测试。独立 Chrome 使用真实 content.js / popup.js 和预设字幕、账单数据验证拖动（约 170 px）、复位、原文开关、语言选择及 390 px 弹窗无横向溢出。真实本机中继已使用现有密钥完成 Usage Logs 只读请求；使用随机不存在的连接编号验证返回“未归账”，没有把这次验证称为真实翻译账单对账。截图位于 `output/playwright/captions-draggable.png`、`captions-bilingual.png` 和 `popup-cost-controls.png`，其中金额和字幕是测试数据。

本轮保持原生 JavaScript 实现，不新增依赖。估算公式和归账查询各自独立，避免把费用逻辑混入字幕缓冲；未引入账户或账单数据库。

## 当前限制

- 当前只接入 Soniox。其他供应商的成本比较见 `research/2026-09-07-provider-and-cost-review.md`，尚未完成同一批日语样本的质量对比。
- 需要本机中继运行，不支持直接填写公网中继地址；这不是普通消费者一键安装即用的正式发行版本。
- 没有声称已验证日语识别准确率、中文翻译质量、端到端延迟或真实每小时账单。系统连接成功也不等于供应商质量验证完成。
- 顶层标准 HTML 音视频的暂停/恢复路径已测试。跨域 iframe 内播放器的事件、各站点全屏实现、画中画和受保护媒体尚未完成兼容性验证。标签页采集会包含该标签页播放的所有声音。
- 暂停会断开翻译连接，但保留本机采集以便恢复；点击“停止”才完整释放采集音轨。无法检测到暂停事件的播放器可能继续发送静音，应手动停止。
- 不绕过 DRM，不下载视频。用户需自行选择其有权使用的内容。
- 尚未实现语音同传、字幕导出、收费、用户额度或云端部署。

## 说话人标记（0.1.3）

Chrome 翻译连接开启 Soniox 的 `enable_speaker_diarization`。字幕在同一连接内按 `speaker` 分组，用“说话人 1 / 2 …”及六种循环颜色区分；编号始终显示，所以颜色重复时仍可区分。插件弹窗“显示说话人编号与颜色”可即时切换并保存，不重连；该开关只控制显示，服务端仍接收说话人元数据。

原文与译文独立使用各自 token 的编号，不将当前原文说话人套给延迟译文。缺失或不符合已支持格式的编号显示普通字幕；不会猜测性别、角色名或真实身份。临时 token 的编号可随供应商修订，最终 token 只追加一次。保留原有文本字段，网页预览和桌面端原有文本消费方式保持兼容。

暂停、跳转、换语言后的新连接会清空字幕缓冲；第二段起提示“说话人编号已重置”，标签加上连接段数。同号不表示跨连接同一人。未实现声纹匹配、角色识别或手动命名。

仍保留当前句末检测配置。Soniox 提醒实时区分可能误判，提前定稿会降低区分准确率；本轮未对实际视频测量说话人区分准确率，也未承诺译文一定带编号。参考：[说话人区分](https://soniox.com/docs/stt/concepts/speaker-diarization)、[WebSocket 字段](https://soniox.com/docs/api-reference/stt/websocket-api)。

验证：22 项自动化测试包含上游配置和字段透传、迟到译文、临时编号修订、无编号保留、分组长度限制、重连分段及开关不重连。独立 Chrome 运行真实缓冲及渲染代码，以预设双说话人数据验证颜色、显示开关、重连提示、缺失编号及修订；截图 `output/playwright/speaker-captions.png`。未向 Soniox 发送真实测试音频。本轮未新增依赖，分组逻辑集中于字幕缓冲，显示设置沿用现有消息通道。

0.1.4：字幕浮层的日文、译文、说话人标签、状态提示和操作按钮统一左对齐；字幕面板左右各留 16 px，原文与译文共用左边缘。仅调整现有 CSS，无新增依赖或识别逻辑变更。
验证：独立 Chrome 中检查日文、译文、编号重置提示、暂停提示的计算样式均为左对齐、左内边距 16 px，文本块左边缘一致；多行译文和缩小窗口后的边界检查通过。截图 `output/playwright/captions-left-aligned.png` 为预设文本；语法检查与扩展打包通过。


## 字幕框宽高调整（0.1.5）

拖动字幕浮层右下角「↘ 拖动调整宽高」可分别或同时增减宽高，方向键也可微调。字号不随框体缩放；布局根据实际宽度换行，按完整文字行分配显示高度并跟随最新内容。开启原文时两条字幕轨共享高度，隐藏原文后译文独占可用高度。尺寸限制在网页可视区域内，窗口缩小时会收拢到边界内。「复位」同时恢复默认位置与自动尺寸；手动尺寸在当前页面内保留，刷新后重置。

Chrome 采集端的字幕缓冲改为每条语言轨最多 4,000 个字符，在同一连接内跨句保留近期文字。扩大框体后可显示更多已经收到的字幕，无需重新请求识别。暂时没有新内容时，手动尺寸模式保留当前显示；默认自动尺寸模式仍按原有的 9 秒规则清屏。暂停、跳转、换语言和停止会清空连接缓冲；不跨连接拼接说话人身份。历史仅在内存中，不写入本地字幕文件或存储。其他调用者继续使用缓冲类的原默认行为。

验证：23 项自动化测试通过，包括多句保留、临时修订、4,000 字符边界及重置；独立 Chrome 以真实缓冲/渲染代码和预设字幕验证宽高拖动、可见文字增多、字号不变、双语高度共享、窗口边界与复位。截图 `output/playwright/caption-resize-before.png`、`caption-resize-after.png`。只调整本地布局和有界内存缓冲，无新增依赖或额外 ASR 请求。
