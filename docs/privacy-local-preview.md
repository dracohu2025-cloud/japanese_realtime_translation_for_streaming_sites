# 本机开发版数据说明

适用范围：本仓库的 Chrome 扩展与本机 Node 中继，版本 0.1.5。此文记录当前行为，不是已上线服务的正式隐私政策。

## 处理的数据

用户开启翻译后，扩展采集所选标签页的音频，转换为 PCM，通过本机 WebSocket 中继发送至 Soniox；术语和背景说明也会随会话发送。字幕由 Soniox 返回，经本机中继交给扩展显示。每段连接发送随机 client_reference_id，用于事后匹配供应商用量日志；扩展打开时可由本机服务查询项目日志，仅返回本次编号匹配的费用汇总。

当前实现不向 Soniox 发送视频画面、网页地址、页面正文或浏览历史。标签页音频可能包含视频以外的提示声或同页其他播放器声音。

## 本地保存与日志

- 供应商密钥：保存在用户自己的 `.env` 或进程环境中；不写入扩展安装包，也不通过配置接口返回浏览器。
- 扩展本地存储：本机服务地址、配对码、术语、背景说明、字体、目标语言、原文显示和说话人标记显示选项。
- 临时会话存储：当前或最近一次的标签 ID/标题、状态、已发送时长、音量及费用元数据。费用元数据包含随机连接编号、起止时间、模型、字符计数、估算值和已归账金额，不包含字幕正文；关闭 Chrome 或重新加载扩展后清除，下次翻译覆盖上次会话。
- 运行内存：当前音频缓冲、近期字幕（Chrome 每条语言轨最多 4,000 个字符）及供应商返回的会话内说话人编号；停止后关闭音轨及上游连接，清除当前字幕。
- Node 日志：事件时间、随机会话 ID 和发送音频秒数；代码不记录音频、字幕、API key 或配对码。

本实现没有账户、广告分析、音视频文件存储或字幕历史数据库。此处的“不保存”仅描述本项目代码，不代表第三方供应商的留存承诺；使用云端识别前需核实所选供应商账户适用的数据处理与留存条款。

## 用户控制

翻译必须由用户主动开启。点击“停止”、关闭被采集标签页或进入错误处理路径会释放采集音轨。播放器暂停时保留本机音轨以支持自动恢复，同时断开翻译连接；如需完整停止采集，请点击扩展的“停止”。

正式上线前，需根据实际运营主体、供应商、服务地区和留存策略补齐联系人、用户权利、删除机制与商店披露。
