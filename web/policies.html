取消自动续订不会自动退还已付款项。退款获批并处理后，相应订单的时长会按退款比例扣回；已使用时长不会变成负余额。支付争议期间可能暂停对应订单的剩余时长，争议解决后按结果调整。

本说明不限制适用消费者法律赋予你的退款、撤回或其他权利。

我们按日汇总产品视频播放、播放完成和安装入口点击次数，不设置访客标识，不将这些事件关联到账户；保留最近 90 天的汇总。启用 Global Privacy Control 或 Do Not Track 时不提交这些事件。

隐私与数据

登录后，我们会记录首次可观察的粗粒度来源类别（例如搜索、社区或直接访问），结合账户的试用、用量和购买记录生成内部汇总统计。不为此设置 Cookie 或浏览器存储，不记录完整来源网址或搜索词；浏览器启用 Global Privacy Control 或 Do Not Track 时不提交来源。来源记录与账户关联，随账户保留，可联系客服申请删除。

登录使用邮箱验证码。我们保存邮箱、登录会话、订单关联、时长账本和故障元数据，用于登录、提供服务、计费、防滥用和处理支持请求。浏览器使用必要的登录 Cookie 和本地设置，不使用广告追踪 Cookie。

只有你主动开始翻译后，插件才会采集所选标签页的音频并经云端发送给语音处理服务。停止翻译后停止采集。Kotoba 不持久保存音频和字幕正文；云端处理期间和浏览器当前会话中会暂时保留必要数据。

我们使用 Cloudflare 托管服务、人机验证及不使用 Cookie 的网站访问与性能统计、Resend 投递验证码、Stripe 处理付款，目前使用 Soniox 处理语音与翻译。这些服务可能在你的所在地以外处理数据，并受其各自的数据处理条款约束。银行卡资料由 Stripe 处理，不经过 Kotoba 服务器。

发送限频记录定期清理，IP 用带密钥的摘要计数；账户、订单和使用记录在提供服务、处理争议及履行适用留存义务所需期间保留。你可以联系客服申请访问、更正或删除个人数据；依法需要保留的财务记录可能无法立即删除。

Kotoba 对通过 Chrome API 获取的数据遵守 Chrome 网上应用店用户数据政策，包括 Limited Use 要求。数据仅用于提供或改进用户可见的翻译功能，不出售，不用于个性化广告、信用评估或放贷。你自愿填写的内容背景和术语也会随翻译请求发送；请勿填写敏感信息。

安装 Chrome 插件

可从 Chrome 商店安装，也可使用本站的手动安装包。以下步骤适用于手动安装。

  1. 下载并解压 Kotoba Live 扩展包。
  2. 在 Chrome 地址栏输入 chrome://extensions，打开开发者模式。
  3. 点击“加载已解压的扩展程序”，选择含 manifest.json 的文件夹。
  4. 登录本站获取连接码，在插件中连接账户，然后打开视频开始翻译。

商店安装的版本由 Chrome 自动更新。手动安装的版本需重新下载、替换原文件夹中的文件，再到 chrome://extensions 点击 Kotoba Live 的重新加载按钮。
