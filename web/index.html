01 / 服务

配置语音服务

在项目的 .env 中设置 Soniox 密钥，重启本机服务。密钥保留在服务端。

npm start
02 / 插件

加载 Chrome 扩展

打开 Chrome 扩展管理页，启用开发者模式，选择「加载已解压的扩展程序」，载入项目的 extension 文件夹。

chrome://extensions
03 / 连接

复制本机配对码

在插件设置中粘贴配对码。然后打开日语视频，点击插件的「开始翻译」。
