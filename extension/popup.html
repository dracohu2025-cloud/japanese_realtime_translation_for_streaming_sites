预估与真实费用怎么算？

预估按 stt-rt-v5（2026-09-07）价格：输入音频 $2/百万 token，输入及输出文字各 $4/百万 token。按每小时音频约 30,000 token、每字符约 0.3 token 换算；包含背景提示、日文转写和译文。它不是固定小时价，也不是扣款金额。

音频估算取已发送时长与连接时长的较大值，每秒更新。静音但保持连接仍累计；检测到暂停或拖动进度时断开连接，暂停期间冻结。恢复、换语言会新建一段连接并重新发送背景提示，本次各段费用累加。隐藏原文不减少转写费用。

真实金额来自 Soniox Usage Logs 的 cost_usd，按独立连接编号匹配、按记录 UUID 去重。请求结束后才可能出现记录，官方未承诺具体延迟；未出现不代表免费或零费用，失败请求也可能没有完整记录。

弹窗打开时最多每 15 秒查询一次；归账显示已匹配段数。预估覆盖全部段，已归账只含找到的段，两者不能相加。断线收尾、token 换算会产生差额，以供应商记录为准；这不是含税发票或信用余额实际扣减。

只展示本次或最近一次翻译，关闭 Chrome 后清除。再次开始会替换上一会话；历史账单请查看 Soniox 控制台。这里仅计 Soniox API 成本，不含服务器和其他服务费用。其他模型不提供价格预估。
